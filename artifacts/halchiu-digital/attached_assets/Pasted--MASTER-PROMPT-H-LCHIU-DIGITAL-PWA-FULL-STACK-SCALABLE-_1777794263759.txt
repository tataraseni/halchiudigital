# MASTER PROMPT – „HĂLCHIU DIGITAL” (PWA FULL STACK + SCALABLE GOVERNMENT PLATFORM)

## 0. CONTEXT

Construiește o aplicație **PWA full-stack** numită „Hălchiu Digital”, care devine un sistem digital local pentru administrație publică, comunitate și economie locală.

⚠️ REGULĂ CRITICĂ:

* NU rescrie sistem existent
* NU modifica structuri existente
* DOAR extinde incremental (patch-based architecture)
* TOTUL trebuie să fie backward compatible

---

# 2. PWA REQUIREMENTS

Aplicația trebuie să fie 100% PWA:

* install prompt (Add to Home Screen)
* Web Push Notifications
* Service Worker caching:

  * feed
  * evenimente
  * anunțuri
* offline fallback page
* lazy loading + pagination
* fast load (<1s perceived)
